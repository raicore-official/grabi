# Grabi website

Static, dependency-free landing page for Grabi.

## Vercel

When importing the repository in Vercel:

1. Set **Root Directory** to `website`.
2. Select **Other** as the framework preset.
3. Leave the build command empty.
4. Deploy.

The APK button points to the verified [Grabi v0.3.1 release](https://github.com/raicore-official/grabi/releases/tag/v0.3.1).
